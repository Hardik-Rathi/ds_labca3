# DS-EXP3 — Measuring Central Tendency and Variability of Data

**Dataset:** [`Sub_Division_IMD_2017.csv`](./Sub_Division_IMD_2017.csv) — IMD subdivision-wise monthly rainfall (1901–2017). Sample used: ANNUAL rainfall of Konkan & Goa (117 years).

**Use case:** KJS-AGR-01 — AI Irrigation Advisory System

## What's covered
1. Mean, median, mode, range, variance, standard deviation, IQR and CV using built-in functions (single and multiple attributes)
2. The same measures computed manually, without in-built functions
3. Grouped data analysis (250 mm class intervals)

## Files
- `exp3_statistics.py` — standalone script
- `EXP3_Central_Tendency_16014324020.ipynb` — notebook with output
- `EXP3_notebook.pdf` — notebook as PDF
- `Sub_Division_IMD_2017.csv` — dataset

## Key result
Mean = 2987.53 mm, median = 2968.5 mm, std = 486.92 mm, IQR = 578.2 mm, CV = 16.3%. Manual and built-in results match.
